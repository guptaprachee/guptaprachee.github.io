# Prachee Gupta — Portfolio

A responsive, accessible, static portfolio with a charcoal editorial design, off-white typography, a portrait area, a simple experience timeline, and readable project narratives. No installation, paid plan, custom domain, or build step required.

## Publish on GitHub Pages

1. Sign in to GitHub as **guptaprachee**.
2. Create a **public** repository named **guptaprachee.github.io**. If it already exists, inspect it before replacing anything.
3. Extract this ZIP. Upload `index.html`, `resume.pdf`, and `.nojekyll` from the portfolio folder to the repository root (not a nested folder). Commit the files to `main`.
4. Open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, then **main** and **/(root)**. Save.
5. Wait for the Pages deployment to finish. The intended URL is **https://guptaprachee.github.io/**. This address is not live until deployment succeeds.

## Review before publication

Content is based on the supplied résumé. Confirm the employment descriptions and performance figures are accurate and suitable for public sharing. The included résumé is a public-facing copy: phone number and the unverified availability claim have been removed. College email, LinkedIn, and GitHub are available in the résumé.

LinkedIn and GitHub URLs were extracted from the résumé. The contact button opens LinkedIn; there is no contact form or database.

## Edit and preview

Open `index.html` in a browser. All styles and the small copyright-year script are inline. Edit text directly in `index.html`; replace `resume.pdf` to update the download. The page uses system fonts and has no third-party scripts or trackers.

## Add a portrait

Upload a photo to the repository as `portrait.jpg`. Replace the contents of the `<div class="portrait">` element in `index.html` with `<img src="portrait.jpg" alt="Prachee Gupta">`. The existing styling crops the image to a portrait frame. Until a photo is provided, this area displays a PG monogram.
